# Document Utilities

Context and router for the document-utilities domain. This domain provides skills for extracting, converting, and processing document formats (PDFs, diagrams) into machine-readable or renderable outputs. It serves as the central hub for any file-format transformation that agents need during research, reporting, or content ingestion workflows.

## Available Skills

- [extract-pdf](skills/extract-pdf/SKILL.md): Extract readable text content from a PDF file using pypdf.
- [mermaid-to-svg](skills/mermaid-to-svg/SKILL.md): Convert a Mermaid `.mmd` file to SVG.
