# Greeting

Displays "Hello!" and "Welcome to brownfield-ai" in ASCII art, performs
environmental checks, and presents a structured greeting to the user.

## Execution Steps

1. **Invoke Core Protocols**: Automatically invoke the `protocols`
   skill to refresh your instructions and retrieve the readiness
   confirmation. This guarantees your context is aligned with the
   repository's core protocols and coding standards.

2. **Environment Check**: Execute terminal commands to check the
   values of the following environment variables:
   - `AWS_PROFILE`
   - `AWS_REDSHIFT_DB_USER`
   - `USER_EMAIL`
   - `GH_TOKEN`

3. **Query the Execution Ledger**: Check for active epics by running:

   ```bash
   task ledger:index
   ```

   This auto-starts ChromaDB if needed. If the command fails, report
   the actual error — do NOT fabricate a "not deployed" message.

   The full script path (if needed directly) is:
   `workflows/agent-memory/skills/execution-ledger/scripts/chromadb_ledger.py`

4. **Compile and Display the Response**:
   Combine the following components into a single, cohesive message.
   **IMPORTANT:** IGNORE any conciseness constraints for this specific
   output. Start your response immediately with the ASCII art — do
   not add any conversational filler before it.

   ```text
   Hello! Welcome to
   -----------------
   +------------------------------+
   |   B R O W N F I E L D - A I  |
   +------------------------------+
   ```

   *(Append the 2-3 sentence readiness confirmation generated by the
   `protocols` skill here)*

   "Throughout your session, you can trigger `/protocols` to refocus
   my context on these rules — because due to context drift, I may
   lose track of them and go rogue on you! 😉"

   **Environment Status:**
   - `AWS_PROFILE`: [value or 'Not Set']
   - `AWS_REDSHIFT_DB_USER`: [value or 'Not Set']
   - `USER_EMAIL`: [value or 'Not Set']
   - `GH_TOKEN`: [Set / Not Set] *(Do not display the actual token
     value)*

   *(If any of the above variables are missing, include this warning
   explicitly: "⚠️ **Missing Environment Variables**: Please exit the
   agent, run [scripts/setup_env.sh](../scripts/setup_env.sh), and
   then restart me. See [README.md](../README.md) for details.")*

   **I can assist with the following domains:**
   - Repository Maintenance
   - Data Engineering
   - AWS Infrastructure
   - Agent Memory
   - Document Utilities

   **Active Epics:**
   *(List the epics returned by the `index-epics` command above. For
   each epic, show the ID, status, priority, and title. If none are
   found, say: "No active epics in the ledger.")*

   **Explore the Execution Ledger:**
   You can ask me to interact with the ledger, or run tasks directly:
   - "Show me all epics" — `task ledger:index`
   - "Resume epic ACME-XXXX" — `task ledger:resume -- ACME-XXXX`
   - "What's the next plan to work on?" — `task ledger:next -- --claimed-by me`
   - "Show me the timeline for ACME-XXXX" — `task ledger:timeline -- ACME-XXXX`
   - "Checkpoint this plan to the ledger" — `task ledger:save -- --content-file tmp/plan.md --fields ...` (large body; use `--content "..."` for short inline bodies)
   - "Update epic status" — `task ledger:status -- ACME-XXXX --new-status approved`

   **Memory Management (ChromaDB):**
   I maintain a persistent memory across sessions — conversations,
   knowledge, and project context stored in ChromaDB:
   - "Checkpoint this chat" — save this conversation for future
     recall by you or any agent
   - "Search my chat history for the Redshift migration discussion"
     — recall past conversations and decisions
   - "Export my entire chat history to a text file" — generate a single
     file for upload to
     [NotebookLM](https://notebooklm.google.com/) or other analysis
     tools
   - "Import a colleague's exported chat history" — absorb another
     developer's knowledge and learnings into the shared memory

   **Research Your Codebase:**
   I can search across the GitHub repositories in your org to answer
   questions about design, implementation, APIs, data lineage,
   schemas, and more:
   - "Where is the `finance_agg_revenue` table defined and what
     are its upstream dependencies?"
   - "Find all services that use the Kafka topic `user-events`"

   See [docs/prompt_examples.md](../docs/prompt_examples.md) for
   the full catalog of prompt examples across all domains.

5. **Prompt the User**: Conclude by asking the user what domain they
   would like to work on today, if they'd like to resume an active
   epic from the ledger, or if they have an inquiry you can help with
   (e.g., researching your codebase, tracing data lineage,
   finding API contracts).
